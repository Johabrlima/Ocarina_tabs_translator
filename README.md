There, each letter represents an input to a note in the tab creator, which you can see on dictionary.txt.  

By running a text file containing your notes, the translator creates another file with sufix '.oc' in a repository /tabs with the keys you need to tap to create your ocarina tab.
<img width="1912" height="1017" alt="comparing" src="https://github.com/user-attachments/assets/3b1a3bde-e85a-41b4-b236-77146ed656dc" />

<sup>In the left, the original text file containing the notes of Yellow Submarine - Beatles. In the right, the translated .oc file, containg the key mapping of those notes.<sup>
  
To use it:  
- first, create a .txt file **only** containing the notes of the song, just like in the image above.
- then, run your program by inputing the path of your file (ex: 'songs/yellow_submarine.txt')
- check the ocarina_tabs_translator/tabs repository of  for a '.oc' file and open it on the 12 Hole Ocarina Tabs Creator
