This translator is based on the key mapping of:  
https://panzi.github.io/ocarina_tabs/  

Each letter represents an input to a note in the tab creator, as you can see on dictionary.txt.   
By running a text file containing your notes, the translator creates another file with sufix '.o' with the keys you need to tap to create your ocarina tab.

To use it:  
- first, create a txt file **only** containing the notes of the song
- then, run your program by inputing the path of the file (ex: 'Songs/yellow_submarine.txt')
- check the mother repository of your input for a '.oc' file and open it
